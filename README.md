# 中证500动量选股策略回测

大学量化投资课程作业：在中证500成分股上构建、迭代并回测四个选股策略版本，
配套 Streamlit 交互式 Web 应用（支持在线调参重跑回测）。

## 策略版本演进

| 版本 | 核心思路 | 全区间累计 | 年化超额 | 最大回撤 | IR(全/外) |
|---|---|---|---|---|---|
| V1 基线版 | 250日新高动量 + ROE/PB 全局阈值 | 37.62% | -2.61% | -67.84% | 0.01 / 0.27 |
| V2 行业中性增强 | 复合动量60% + 行业中性质量40%，40只等权 | 14.84% | -5.10% | -44.06% | -0.32 / -0.20 |
| **V3-A 风控版（最优）** | V2 + 固定止损-12% + 动量排名退出 | **124.70%** | **+4.45%** | **-25.53%** | **0.24 / 0.18** |
| V3-B 海龟风控 | V2 + ATR×2跟踪止损 + 分档止盈 + 100日强平 | 83.32% | +1.46% | -18.33% | -0.02 / -0.23 |
| 基准 | 中证500（价格指数） | 65.57% | — | -41.81% | — |

回测区间 2019-01 ~ 2026-10（样本内/外以 2022-12-31 分界），月度调仓、次日开盘执行。

## 核心发现

- **V3-A 是唯一双区间信息比率均为正的版本**——止损+排名退出把 V2 的"回撤可控但收益不足"
  变成"收益回撤双优"（V2→V3-A：年化 +9.6pp，回撤改善 18.5pp）
- **参数敏感性**：V3-A 止损线处于稳健平台区（-10%/-12% 差距小，-15% 明显劣化）；
  V3-B 的 ATR 倍数为高敏感参数（×1.5 事后占优，但属事后优化=过拟合，正式版保留先验 ×2.0）
- **执行时点对照**：V2 开盘执行 14.84% vs 收盘执行 9.13%——差距源于策略本质而非执行细节
- **未来函数实证案例**：V1 初版因行号切片引入未来函数虚高至 90.1%，
  改为日期切片后修正为 37.62%（约 10% 的中后期上市/退市股票受影响）

## 项目结构（数据层 / 策略层 / 风控层 / 引擎层 / 展示层分离）

```
quant500_momentum/
├── config.py               # 全局参数（策略/成本/区间，所有可调参数集中于此）
├── data_loader.py          # 数据层：baostock 接口 + 本地缓存（断点续传、持久登录）
├── filters.py              # 统一预处理：ST/停牌/涨跌停/流动性后5%剔除
├── strategy.py             # V1 选股
├── strategy_v2.py          # V2 选股（复合动量 + 行业中性质量 + 均线过滤）
├── backtest_v2.py          # V2 回测引擎（开盘/收盘双执行模式）
├── backtest_v3a.py         # V3-A 引擎（止损 + 排名退出）
├── backtest_v3b.py         # V3-B 引擎（ATR 跟踪止损 + 分档止盈 + 强平）
├── metrics.py              # 绩效指标（年化/夏普/回撤/卡玛/月度胜率/信息比率IR）
├── run_backtest*.py        # 各版本主脚本
├── run_sensitivity.py      # 参数敏感性测试（V3-A 止损三档 + V3-B ATR 三档）
├── build_compare.py        # 四版本 8 列对比表（带自校验断言）
├── app.py                  # Streamlit Web 应用（展示 + 在线调参回测）
├── download_data.py        # 数据下载入口（第一步）
├── check_env.py            # 环境自检
└── output/                 # 回测产物（净值/指标/交易记录/敏感性结果，已含在仓库中）
```

## 如何运行

```bash
# 1. 安装依赖（Python 3.10+）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 下载数据（baostock 免费接口，国内直连，首次约 20~40 分钟，约 235MB 缓存到 data/）
python download_data.py

# 3. 跑回测（任选）
python run_backtest.py          # V1
python run_backtest_v2.py       # V2（另设 close 对照，见脚本内说明）
python run_backtest_v3a.py      # V3-A
python run_backtest_v3b.py      # V3-B
python run_sensitivity.py       # 参数敏感性（约 35 分钟）
python build_compare.py         # 四版本对比表

# 4. 启动 Web 应用
python -m streamlit run app.py
```

> 注意：`data/`（原始数据缓存，235MB）不纳入版本控制，需自行下载；
> 回测产物 `output/` 已包含在本仓库，可直接查看结果。

## Web 应用功能

- **四版本总览**：对比总表 + 交互式净值曲线（可缩放/悬停）
- **单版本详情**：三段绩效、年度收益、风控触发统计、持仓快照
- **参数敏感性**：V3-A 止损线 / V3-B ATR 倍数三档对照
- **在线回测（调参实验）**：调持仓数/动量权重/止损线/ATR 倍数等参数，
  在浏览器里完整重跑回测引擎（单次约 5 分钟），结果不覆盖正式版产物
- **口径与说明**：数据源、成本假设、无未来函数设计、局限性

## 数据与口径声明

- **baostock**（免费，无需注册）：A股日线、中证500历史成分股、ST/停牌状态、
  市净率 PB(MRQ)、季度财务数据（ROE，含公告日期）
- 股票池：各调仓日的**历史**中证500成分股快照（避免幸存者偏差），全区间共 1109 只
- 成本：双边佣金 0.03% + 卖出印花税 0.1% + 滑点 0.2%（买 0.23% / 卖 0.33%）
- 防未来函数：信号日用 T-1 及更早数据；财务数据按公告日（pubDate）对齐
- 说明：AI 编程智能体（WorkBuddy）辅助开发了本项目的工程框架与代码，
  策略逻辑、参数选择与回测结论由本人理解并答辩。

## 局限性

1. 基准为中证500价格指数（未含股息再投资），策略超额收益估计偏保守
2. 行业中性以证监会行业 + 成分等权近似基准行业权重
3. V3-B 的 ATR 倍数为高敏感参数，存在参数选择偏差风险（报告中如实披露）
4. 日线粒度：未考虑盘中价格路径，止损按"收盘触发→次日开盘成交"落地
5. 未建模大额资金冲击成本与分红送转的现金流处理
